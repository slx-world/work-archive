# 影刀 RPA 使用说明

将本仓库中的发货单处理脚本做成可重复调用的影刀指令。

## 1. 环境准备

在影刀运行机器上安装依赖：

```bash
pip install openpyxl
```

把本项目放到影刀可访问的目录，例如：

```text
D:\work-archive\projects\fahuodan-excel-rpa\
  process_shipment_excel.py
  yingdao_command.py
  data\
  docs\
```

若使用「Python」组件，请把该目录加入 `PYTHONPATH`，或把 `process_shipment_excel.py` 与指令代码放在同一目录。

## 2. 自定义指令参数

| 方向 | 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- | --- |
| 输入 | `file_path` | 文本 / 文件路径 | 是 | 源 Excel 完整路径 |
| 输入 | `column_names` | 文本 | 建议 | 需要向下填充的列名，逗号分隔 |
| 输入 | `output_name` | 文本 | 建议 | 处理后的文件名或路径（可省略 `.xlsx`） |
| 输入 | `sheet_name` | 文本 | 否 | 工作表名；空则取第一个。样例表为「发货单详情」 |
| 输入 | `dedupe` | 布尔 / 文本 | 否 | 是否整行去重，默认 `True`；可传 `"True"` / `"False"` |
| 输出 | `result` | 文本 | — | 处理后文件的完整路径 |

推荐 `column_names`（与 `data/examples` 表头中五列主字段一致）：

```text
发货单号,物流中心编码,创建时间,发货单状态,物流商
```

`货件单号`、`货件状态` 一般不需要填进 `column_names`（它们本身不是合并列）。

## 3. 指令代码

调用模块选择 `main` 或 `process_shipment_excel`：

```python
from process_shipment_excel import main

result = main(
    file_path,
    column_names,
    output_name,
    sheet_name,   # 可传 None 或 ""
    dedupe,       # 可传 True / False / "False"
)
```

或使用模板：

```python
from yingdao_command import execute

result = execute(file_path, column_names, output_name, sheet_name, dedupe)
```

可视化流程若以字典传参，可用：

```python
from process_shipment_excel import run_from_args

result = run_from_args(args)  # 写回 args["result"]
```

## 4. 流程编排建议

1. 下载 / 定位发货单 Excel，得到 `file_path`
2. 调用本指令，得到 `result`（处理后路径）
3. 用「打开 Excel / 读取区域 / 循环」读取 `result`
4. 后续业务（回传、登记、通知等）

本地可用样例自测：

- 源：`data/examples/发货单-示例-含合并单元格.xlsx`
- 期望结果：`data/processed/发货单-示例-已处理.xlsx`（3 行业务数据）

## 5. 输出规则

- `output_name` 仅为文件名时：保存在**源文件同目录**
- `output_name` 含目录或为绝对路径时：按该路径写入（目录不存在会自动创建）
- 未带后缀时自动补 `.xlsx`
- 输出表无合并单元格，工作表名与源表一致（样例为「发货单详情」）

## 6. 常见问题

**报错 `from __future__ imports must occur at the beginning of the file`**  
影刀「调用模块」会在脚本前插入包装代码，导致 `from __future__ import ...` 不再位于文件开头。  
本仓库的 `process_shipment_excel.py` **已去掉**该语句；若你本地仍报错，请重新同步/替换模块文件后再运行。

**调用模块多出一个无名参数**  
影刀解析函数签名时，若最后一个形参后面带了尾随逗号（如 `dedupe=True,`），会多出一格空输入。本仓库已去掉该逗号；留空也不影响，但建议同步最新代码。

**报错「找不到文件」**  
检查 `file_path` 是否为绝对路径，且影刀运行账号有读权限。

**报错「列名在表头中不存在」**  
核对第一行表头是否与 `column_names` 完全一致（含空格、全半角）。样例七列表头为：  
`发货单号,物流中心编码,创建时间,发货单状态,物流商,货件单号,货件状态`。

**报错「工作表不存在」**  
核对 `sheet_name`；样例工作表名为 `发货单详情`。留空则自动取第一个表。

**行数比预期多**  
默认会整行去重。若需要保留重复明细，将 `dedupe` 设为 `False` / `"False"`，或命令行加 `--no-dedupe`：

```python
from process_shipment_excel import process_excel

result = process_excel(file_path, column_names, output_name, dedupe=False)
```
