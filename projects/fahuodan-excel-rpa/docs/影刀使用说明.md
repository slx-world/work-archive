# 影刀 RPA 使用说明

将本仓库中的发货单处理脚本做成可重复调用的影刀指令。

## 1. 环境准备

在影刀运行机器上安装依赖：

```bash
pip install openpyxl
```

把本仓库放到影刀可访问的目录，例如：

```text
D:\work-archive\
  process_shipment_excel.py
  yingdao_command.py
  data\
  docs\
```

若使用「Python」组件，请把该目录加入 `PYTHONPATH`，或把 `process_shipment_excel.py` 与指令代码放在同一目录。

## 2. 自定义指令参数

| 方向 | 参数名 | 类型 | 说明 |
| --- | --- | --- | --- |
| 输入 | `file_path` | 文本 / 文件路径 | 源 Excel 完整路径 |
| 输入 | `column_names` | 文本 | 需要向下填充的列名，逗号分隔 |
| 输入 | `output_name` | 文本 | 处理后的文件名（可省略 `.xlsx`） |
| 输出 | `result` | 文本 | 处理后文件的完整路径 |

推荐 `column_names`：

```text
发货单号,物流中心编码,创建时间,发货单状态,物流商
```

`货件单号`、`货件状态` 一般不需要填进 `column_names`（它们本身不是合并列）。

## 3. 指令代码

```python
from process_shipment_excel import main

result = main(file_path, column_names, output_name)
```

或：

```python
from yingdao_command import execute

result = execute(file_path, column_names, output_name)
```

## 4. 流程编排建议

1. 下载 / 定位发货单 Excel，得到 `file_path`
2. 调用本指令，得到 `result`（处理后路径）
3. 用「打开 Excel / 读取区域 / 循环」读取 `result`
4. 后续业务（回传、登记、通知等）

## 5. 输出规则

- 输出文件保存在**源文件同目录**
- 文件名由 `output_name` 决定；未带后缀时自动补 `.xlsx`
- 输出表无合并单元格，适合影刀按行循环

## 6. 常见问题

**报错「找不到文件」**  
检查 `file_path` 是否为绝对路径，且影刀运行账号有读权限。

**报错「列名在表头中不存在」**  
核对第一行表头是否与 `column_names` 完全一致（含空格、全半角）。

**行数比预期多**  
默认会整行去重。若需要保留重复明细，命令行加 `--no-dedupe`，或在代码中调用：

```python
from process_shipment_excel import process_excel

result = process_excel(file_path, column_names, output_name, dedupe=False)
```
