# 数据处理说明

## 问题背景

源发货单 Excel（`data/examples/发货单-示例-含合并单元格.xlsx`）中，  
`发货单号 / 物流中心编码 / 创建时间 / 发货单状态 / 物流商` 使用了大量**纵向合并单元格**。  
同一发货单下 `货件单号 / 货件状态` 又常重复多行。

直接用影刀按行读取时，合并区下方单元格为空，不利于循环处理。

## 字段与文件约定

| 项目 | 值 |
| --- | --- |
| 工作表名 | `发货单详情` |
| 表头（7 列） | 发货单号、物流中心编码、创建时间、发货单状态、物流商、货件单号、货件状态 |
| 向下填充列 | 发货单号,物流中心编码,创建时间,发货单状态,物流商 |
| 源文件 | `data/examples/发货单-示例-含合并单元格.xlsx` |
| 结果文件 | `data/processed/发货单-示例-已处理.xlsx` |
| 结果预览 | `data/processed/发货单-示例-已处理_预览.csv` |

## 处理目标

得到如下形态的扁平表（无合并单元格）：

| 发货单号 | 物流中心编码 | 创建时间 | 发货单状态 | 物流商 | 货件单号 | 货件状态 |
| --- | --- | --- | --- | --- | --- | --- |
| SP260001001 | TEB9 | 2026-10-09 16:31:45 | 已发货 | 示例物流 | FBADEMO00001 | IN_TRANSIT |

## 处理步骤

1. **取消合并**：遍历全部合并区域，取消合并，并把原值写回区域内每一个单元格  
2. **指定列向下填充**：对传入的列名（通常是上述 5 个主字段）做 forward-fill  
3. **删除空行**  
4. **整行去重**（默认开启）：同一发货单重复货件行只保留一条  
5. **另存为新文件**：保证输出工作表 `merged_cells` 为空，表名与源表一致  

## 样例结果

仓库内脱敏示例（与脚本默认参数对齐）：

| 项目 | 数量 |
| --- | --- |
| 源表明细行 | 8 |
| 源表合并区域 | 15 |
| 处理后记录数 | 3 |
| 输出合并单元格 | 0 |

## 命令行复现

```bash
pip install -r requirements.txt
```

Windows：

```powershell
.\scripts\run_example.ps1
```

macOS / Linux：

```bash
bash scripts/run_example.sh
```

等价命令：

```bash
python process_shipment_excel.py \
  "data/examples/发货单-示例-含合并单元格.xlsx" \
  "发货单号,物流中心编码,创建时间,发货单状态,物流商" \
  "data/processed/发货单-示例-已处理.xlsx" \
  --sheet "发货单详情"
```

第三个参数可为文件名或完整路径；传入带目录的路径时会写入对应位置。  
仓库已提供处理好的示例结果与 CSV 预览，可直接打开对照。
