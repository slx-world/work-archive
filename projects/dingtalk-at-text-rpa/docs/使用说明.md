# 钉钉群聊发送文本并 @人 —— 影刀指令使用说明

## 1. 功能

在钉钉企业内部机器人收到群消息后，通过回调里的 `sessionWebhook` 回复一条 Text 消息，并 @ 指定的人（userid 或手机号），或 @ 所有人。

## 2. 前提

- 机器人为企业内部机器人，并在**企业内部群**中使用（开发者后台“调试”群拿不到 `senderStaffId`）。
- 已从回调请求体取得 `sessionWebhook`（临时地址，有时效）和 `senderStaffId`。
- 正文需包含 `@userid`，并配合 `at` 字段才有高亮；指令已自动拼接，无需手工写。

## 3. 创建指令

1. 影刀 → 自定义指令 → 新建指令集 → 添加 Python 模块。
2. 粘贴 `dingtalk_at_rpa.py` 的内容（推荐，免安装第三方库）。若选 `dingtalk_at_rpa_requests.py`，需先在影刀的 Python 包管理里安装 requests。
3. 函数 docstring 中的 `* @param` / `* @return` 用于声明指令的输入输出。
4. 在“编辑指令信息”里填写指令动作描述，并确认输入 5 项、输出 1 项（`result`）。

## 4. 指令参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| session_webhook | 文本 | 是 | 回调里的 sessionWebhook |
| content | 文本 | 是 | 要发送的内容 |
| at_user_ids | 文本 | 否 | userid，多个用逗号分隔 |
| at_mobiles | 文本 | 否 | 手机号，多个用逗号分隔 |
| at_all | 开关/文本 | 否 | 是否 @ 所有人，默认 False |
| result（输出） | 字典 | | 钉钉返回结果，errcode 为 0 即成功 |

`at_all` 若在界面上以字符串传入（如 "False"），代码已做转换，不会被误判为 True。

## 5. 在流程中调用

1. 使用“调用模块”，选择该模块和函数 `send_text_at`。
2. 5 个输入参数分别绑定对应变量；默认值（None、False）要替换掉，否则用户填的值传不进去。
3. “返回值存储至”改成 `result`；返回值类型选“字典”，没有则选“任意类型”。
4. 详细对照与步骤清单见 `data/影刀调用模块_参数与步骤.xlsx`。

## 6. 测试

1. 安全测试：临时把 `session_webhook` 填成 `https://example.com/x`，运行后应报“session_webhook 不是有效的钉钉地址”，说明模块已被调用、参数已传入。测试后把参数改回变量。
2. 真实测试：用机器人收到 @ 消息时的真实 sessionWebhook 发送，返回 `errcode` 为 0 即成功。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 提示不是有效的钉钉地址 | sessionWebhook 域名不在白名单，核对来源；必要时调整 `_ALLOWED_HOSTS` |
| 提示 content 不能为空 | 检查内容变量 |
| 发送成功但没有高亮 @ | 确认为 Text 类型、userid 正确，且在企业内部群中 |
| 钉钉返回错误 | 异常信息中带有 errcode / errmsg，按钉钉文档排查；sessionWebhook 过期也会报错 |
| 请求钉钉失败 | 网络或超时（10 秒），检查网络后重试 |

## 8. 安全提示

不要把真实 sessionWebhook、userid、手机号写进代码或提交到仓库；示例统一使用 demo 前缀的虚构值。
